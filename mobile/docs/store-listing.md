### Full description (الوصف الكامل)

```
تطبيق ولي الأمر الرسمي لمدارس الشيخ صالح الشريف للتعليم القرآني.
يُتيح لك متابعة أبنائك يوماً بيوم في واجهة عربية بالكامل تدعم الوضع
المظلم وحجم الخط الكبير.

المزايا:
• قائمة بأبنائك المسجّلين مع تبديل سريع بين ملفاتهم

• الحضور — حلقة إحصائية للنسبة العامة + تقويم شهري ملوَّن + سجل حديث
• النتائج — المعدّل العام وشريط تفصيلي لكل مادة
• الفواتير — بطاقات ملوَّنة بحالة الدفع مع مبلغ متبقٍّ وتاريخ الاستحقاق
• المواد الدراسية — روابط وملفات ينشرها المعلّمون للفصل
• الإشعارات — تنبيهات مجمَّعة زمنياً (اليوم / أمس / هذا الأسبوع / …)

هذا التطبيق مخصّص لأولياء أمور طلاب المدارس فقط، ولا يعمل إلا بحساب
مسبق التسجيل من إدارة المدارس.
```

## 4) Data Safety — تصحيح إعلان جمع البيانات

**Play Console → each app → App content → Data safety**

الإعلان الحالي (`No data collected` / `No data shared`) غير دقيق ويعرِّض
التطبيق لسحب المراجعة. الإعلان الصحيح:

| القسم | الحقل | القيمة |
|---|---|---|
| Data collected | Personal info → Name | ✅ Collected — for account functionality — **Required** |
| Data collected | Personal info → User IDs | ✅ Collected — for account functionality — **Required** |
| Data collected | App activity → App interactions | ✅ Collected — for analytics/app functionality — **Optional** |
| Data collected | Messages → Other in-app messages | ✅ Collected (الإشعارات) — for app functionality — **Required** |
| Data shared | (أي فئة) | ❌ Not shared |
| Encryption in transit | — | ✅ Yes (HTTPS) |
| Data deletion | — | Users can request deletion via support email |

**البريد الرسمي لطلبات الحذف:** يجب أن يكون بريدًا على نطاق المدارس.
